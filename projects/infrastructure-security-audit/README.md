## 프로젝트 소개

주요정보통신기반시설 기술적 취약점 분석·평가 방법 상세가이드의 웹·가상화 선택 항목을 Python 점검 도구로 구성함. 주요 기능은 `Web.py`의 웹 소스·설정 파일 분석과 `VH.py`의 플랫폼별 API·SSH 설정 수집임. 점검 조건·출력 형식 정의와 웹 점검 결과의 오탐·ESXi 연결 오류 분석 수행.

| 항목 | 내용 |
| --- | --- |
| 수행 기간 | 2026년 8월 4일 |
| 역할 | 점검 조건 정의 · 실행 결과 검토 · 오탐 및 수집 오류 분석 |
| 대상 | 웹 애플리케이션 소스·설정 파일, ESXi·XenServer |
| 사용 기술 | Python, Paramiko, pyVmomi, SSH/SFTP, HTTPS vSphere API |
| 소스 | 비공개 저장소에서 관리 |

## 역할

점검 대상·처리 조건·결과 출력 형식 정의, 테스트 환경의 오류 분석 담당. 구현과 테스트 코드 작성에 Codex 활용.

| 작업 | 수행 내용 |
| --- | --- |
| 점검 조건 정의 | 웹 다섯 항목의 요청 메서드·파일 종류별 처리 조건, 가상화 플랫폼별 접속 방식 지정 |
| 실행 결과 분석 | 웹 점검 출력의 오탐, ESXi 패키지·버전·인증서 오류 분석 |
| 판정 수정 | 도움말·일반 문자열 제외, 실제 인증·세션 처리 코드의 탐지 조건 보완 |
| 출력 구성 | 코드별 화면 요약, 파일별 JSON 증적·오류, 민감 패턴 마스킹 |

## 주요 결과

2026년 10월 21일 코드 보관·재검증 과정에서 구문·도움말 실행, 기존 회귀 테스트, 모의 입력 검증 결과 재확인.

| 검증 항목 | 결과 |
| --- | --- |
| Web.py·VH.py | 구문 검사·명령행 도움말 실행 통과 |
| 웹 회귀 테스트 | 규칙·오탐 제외·파일 분기·코드별 요약 등 19개 통과 |
| 가상화 모의 입력 | 접속 방식 분리·ESXi SSH 차단·API 미연결 오류 처리·세션 판정·패치 검증필 처리 등 6개 확인 |
| 테스트 환경 | 웹 출력의 오탐 분석, ESXi 패키지·버전·인증서 오류 분석 |

가상화 6개 검증은 실제 서버 연결 없이 모의 입력으로 수행함. 웹 런타임 동작·외부 WAF·프록시 정책은 정적 점검 범위에서 제외함.

## 핵심 작업

### Web.py | 웹 소스·설정 파일 분석

SSH/SFTP로 지정한 웹 경로의 HTML과 소스 파일을 읽고 파일 종류별 점검 적용. 웹 애플리케이션 소스·서버 설정의 분석을 위해 Apache·Nginx·Tomcat·PHP 표준 설정 경로도 탐색 대상에 포함함.

점검 항목을 오류 노출·인증·비밀번호 복구·세션·로그인 요청 제한의 다섯 항목으로 구분함. 로그인·세션 관련 단어와 실제 처리 코드의 구분을 위해 파일 경로·코드 패턴을 함께 분석함.

| 코드 | 점검 항목 |
| --- | --- |
| EP | 상세 오류·디버그 정보 노출, 오류 페이지 설정 |
| IA | 인증 처리, 클라이언트 측 인증 의존 패턴 |
| PR | 비밀번호 복구 과정의 난수·토큰 처리 |
| IS | 세션 생성·갱신·만료, 예측 가능한 식별자 |
| CC | 로그인 처리, 요청 제한·지연 설정 |

CC는 로그인 처리와 요청 제한·지연 설정을 읽는 정적 점검으로 구성함. 반복 로그인 요청 전송 없음.

### Web.py | 요약과 상세 증적 분리

화면 출력은 코드별 요약, JSON은 파일별 판정·증적으로 분리함. 파일 경로·줄 번호로 탐지 위치를 확인하고 일치 코드와 탐지 조건을 대조함. 수집 오류도 상세 결과에 기록하고 비밀번호·토큰 패턴은 마스킹 처리.

화면 요약의 `취약`에는 `점검 필요`와 `오류`도 포함됨. 의심 코드 탐지와 파일 수집 실패가 같은 요약으로 표시될 수 있어 JSON의 상태·증적·오류를 함께 확인함. `양호`는 수집 범위와 해당 없음 항목을 포함한 정적 분석 결과임.

### VH.py | 가상화 플랫폼별 설정 수집

HV-01~HV-25의 점검 진입점을 구성하고 ESXi·XenServer의 수집 방식을 분리함. ESXi는 pyVmomi를 통한 HTTPS vSphere API 사용, SSH 연결 차단. XenServer는 SSH로 계정·인증·서버 설정을 조회하도록 구성함.

| 플랫폼 | 수집 방식 | 조회 대상 |
| --- | --- | --- |
| ESXi | HTTPS vSphere API, SSH 연결 차단 | 세션·계정·권한·로그·VM 장치·가상 스위치 설정 |
| XenServer | SSH | 계정·인증·시각 동기화·원격 로그 설정 |

판정은 `양호`, `취약`, `검증필`, `오류`, `해당없음`으로 구분함. 수집한 설정값의 조건 판정, 수집 실패, 외부 자료 대조 필요 항목을 구분해 출력함.

패치 항목 HV-25는 버전·빌드 정보만으로 최신 패치 적용을 확정하기 어려워 `검증필`로 처리함. 벤더 권고·변경 이력은 별도 대조 필요함. ESXi 전용 항목은 XenServer 적용 여부를 별도로 판정함. 두 도구의 동작 범위는 설정 조회·결과 출력이며 대상 설정의 자동 변경 기능은 없음.

## 문제 해결

### Web.py | 도움말·일반 문자열 오탐

웹 점검 실행 중 도움말·CI·일반 설정 파일의 로그인·세션 관련 단어까지 탐지되어 `점검 필요`가 과도하게 출력됨. 화면 요약에서 항목을 찾은 뒤 파일별 증적과 실제 코드 동작을 대조함.

JSON의 파일 경로·줄 번호와 실제 코드를 대조해, 로그인 페이지로 이동하는 로그아웃 코드와 계정 입력을 받아 인증하는 처리기를 구분함. 도움말·문서·테스트 경로를 제외하고 인증·세션 패턴을 실제 처리 코드로 좁힘. 회귀 테스트에서 일반 문자열의 제외와 실제 인증·세션 코드의 탐지를 함께 확인함. 보호 조건을 추가로 확인해야 하는 로그인 처리기는 검토 대상으로 유지함.

### VH.py | ESXi 연결 오류

ESXi 점검 실행 중 필수 패키지 누락, Python 3.9·pyVmomi 버전 불일치, TLS 인증서 검증 실패가 차례로 발생함. 설정 수집 전 실행이 중단되어 오류 메시지를 패키지 로딩·버전 호환·인증서 검증 단계로 나눠 분석함.

필수 패키지를 접속 정보 입력 전에 검사하도록 변경하고, Python 3.9 환경의 pyVmomi를 당시 사용 버전인 9.0.0.0으로 조정해 모듈 로딩을 통과함. 이후 TLS 검증에서 중단되어 CA 신뢰·호스트명 문제를 분석하고 CA 파일 지정 방법을 정리함.

ESXi 로그인과 전체 설정 수집은 미완료. 출력된 오류 25개는 개별 설정 검사 이전의 공통 연결 실패가 각 항목으로 전달된 결과임.
